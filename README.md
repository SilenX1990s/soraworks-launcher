# SoraWorks Launcher

A lightweight Minecraft: Java Edition launcher for the players of the SoraWorks
modpack and server community. Built with Tauri (Rust) for Windows, macOS and Linux.

## Features (in development)
- Secure Microsoft account sign-in (OAuth with PKCE / device code) with full game
  ownership verification. No offline or cracked mode.
- One-click modpack install and updates for the SoraWorks modpack
- Performance optimizer: automatic RAM and Java settings for low-end PCs
- Optional crash reports with automatic analysis, sent only with the player's consent

## Privacy
Login tokens are stored encrypted on the player's own device and are never sent to
any third-party server. Crash reports never include tokens or personal file paths.
